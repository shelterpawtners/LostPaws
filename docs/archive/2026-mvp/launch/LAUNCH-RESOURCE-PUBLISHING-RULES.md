# Launch public-resource publishing rules

Public adoption-benefit listings are a resource service. They must never imply a commercial relationship that does not exist.

## Classification

- `public_program`: externally operated adoption/adopter/shelter benefit verified from a current authoritative source.
- `community`: useful animal-welfare/adoption resource without a direct consumer offer or commercial relationship.
- `partner_published`: reserved for organizations actually publishing through ShelterPawtners.
- `exclusive`, `verified_adoption`, `sponsored`, `affiliate`: do not use without the corresponding evidence/approval.

## Minimum evidence

Each public program must record:

- organization/program name;
- concise factual benefit;
- eligibility and geography;
- source URL;
- user destination URL;
- start/end date where applicable;
- verification date;
- disclosure that the program is third-party/publicly listed and not a ShelterPawtners partnership unless explicitly stated.

## Claim quality

- Prefer the company/program's own current page.
- For shelter-specific benefits, describe them as participating-shelter benefits rather than universal offers.
- Do not convert a shelter discount into an adopter discount.
- Do not publish expired promotional values as current.
- Never fabricate savings amounts, availability, partnership, exclusivity, ratings, donations, or adoption verification.
- Time-sensitive programs must expire/suppress when their documented window ends unless reverified.

## Launch content bar

The Marketplace should contain enough current, useful public programs to demonstrate resource-network value before direct PetBiz participation scales, but quality and truthful classification take priority over catalog size.
