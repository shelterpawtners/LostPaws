# Phase Progress Files

Each active phase should maintain a progress file.

Recommended names:

- `PHASE-1-PROGRESS.md`
- `PHASE-2-PROGRESS.md`
- `PHASE-3-PROGRESS.md`
- `PHASE-4-PROGRESS.md`
- `PHASE-5-PROGRESS.md`

Each file should track:

- requirement / Definition of Done gate
- Complete / In progress / Not started / Blocked
- evidence
- remaining action

Agents should update the progress file before meaningful checkpoint commits.
