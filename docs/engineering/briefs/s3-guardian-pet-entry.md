# S3 - Fast guardian pet entry

Follow docs/engineering/briefs/mobile-forms-standard.md. Own: src/main.tsx function `StandardOnboard` (guardian + shelter onboarding) and `GuardianPetDetail`'s route wrapper only, src/components/GuardianPetPassport.tsx, GuardianProfileLite.tsx, GuardianAdoptionVerification.tsx, PetMediaGallery.tsx, AdoptionVerificationResponder.tsx, and new src/components/guardian-forms.css.
Goal: a guardian adds a pet in seconds: step 1 = pet name + species + (optional) photo, big tappable choices instead of dropdowns where sensible; save immediately; then a "Complete your pet's Passport" checklist with optional sections (breed, birthday, vet, microchip, medical, adoption verification) as collapsed accordions that each save independently. Single column, sticky Save bar, camera-friendly photo input (`accept="image/*"` + capture hint), 16px inputs, no side-by-side fields <1024px. Preserve privacy rules in .github/instructions/security.instructions.md (microchip not public etc.).
