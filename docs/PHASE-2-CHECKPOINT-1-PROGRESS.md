## Known limitations

- Platform administrators can see the request and duplicate-review records in the database foundation; their dedicated review UI is intentionally deferred to a later approved admin slice.
- Relationship selection is intentionally limited to an organization the user already manages for a corporate child, or a surfaced candidate for an independent franchise relationship. It does not infer representation from a name.
- Candidate matching is explainable exact-signal matching only. Fuzzy enrichment, external business data, automatic merges, public profiles, and offers are outside this checkpoint.
- Membership revocation retains the membership row with `status = 'revoked'`; routine revocation must not delete that audit-relevant record.
